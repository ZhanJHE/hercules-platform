## 三、故障演练（阶段 A+，模拟 Redis 挂起/恢复）

| 阶段 | 操作 | 观测结果 |
| :--- | :--- | :--- |
| 故障注入 | 应用指向黑洞监听器（接受连接永不响应） | miss 路径首请求 3.4s（建连+命令超时的有界代价） |
| 熔断生效 | 连续 miss 请求 | 熔断 OPEN 后延迟 **7-8ms**（对比无熔断时 60s 级挂起）；`redisDegraded` 持续累计 |
| 击穿防护 | 15 同键并发 | `dbLoad=1`（单飞合并） |
| 故障期写路径 | 选课 | 成功，256ms（DB 事实源，L2 写入降级跳过） |
| 恢复 | 黑洞换 6390→6379 转发器 | 10s 后半开探测成功，2 次探测后 **CLOSED**；L2 经真实 Redis 回填（`l2Hit=1`，8ms） |
